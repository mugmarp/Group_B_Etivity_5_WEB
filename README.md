## Task Overview

The Academic Registrar at Mbarara University of Science and Technology (MUST) is digitizing departmental operations with support from the Deputy Vice Chancellor. Our class has been tasked with proposing and building practical digital solutions.

### The Challenge

**Choose one registrar process** (e.g., examination results, applications, student records, class attendance, transcripts, course registration, graduation clearance, or any other registrar workflow).

**As a team:**
1. Identify the problem and discuss it thoroughly
2. Propose a production-ready digital solution:
   - Define users
   - Define key features
   - Define expected benefits
3. Build an **Express server and API** for the core workflow
4. Create a **Postman collection** to test successful and invalid requests
5. Connect to a **live database** and **frontend**
6. Demonstrate teamwork via GitHub pull requests from each member
